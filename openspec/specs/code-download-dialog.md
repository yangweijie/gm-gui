# 功能代码下载确认框

## 概述
在用户完成加密、解密、签名、验签等核心功能操作后，添加一个确认对话框，询问用户是否需要下载实现这些功能的PHP代码。这将帮助用户更好地理解国密算法的实现方式，并提供实际可运行的代码示例。

## 需求描述
1. 在以下功能操作成功完成后显示确认对话框：
   - SM2加密
   - SM2解密
   - SM2签名
   - SM2验签
   - SM3哈希计算
   - SM4加密
   - SM4解密

2. 对话框内容：
   - 标题：功能代码下载
   - 消息：操作已完成。是否需要下载实现此功能的PHP代码示例？
   - 按钮：下载代码 / 取消

3. 生成的代码应包含：
   - 完整的PHP代码片段，可直接运行
   - 必要的依赖引入语句
   - 详细的注释说明
   - 当前操作的参数和结果示例

## 技术实现

### 代码生成逻辑
- 根据用户执行的具体功能，动态生成相应的PHP代码
- 代码应包含完整的实现流程，从密钥生成到具体操作
- 使用实际项目中的类和方法调用
- 代码格式化良好，符合PSR-12标准

### 代码复制到剪贴板
- 生成代码后，自动将代码复制到系统剪贴板
- 提供视觉反馈，告知用户代码已复制到剪贴板

### 文件生成
- 同时提供下载.php文件的功能
- 文件名格式：`sm2_encrypt_example_20251018_153045.php`（包含时间戳）

## 用户界面设计
- 使用标准对话框组件
- 清晰的消息提示
- 明确的按钮标签
- 操作成功后的状态反馈

## 验收标准
1. 在所有指定功能操作完成后正确显示对话框
2. 生成的代码完整且可运行
3. 代码正确复制到剪贴板
4. 提供代码下载功能
5. 不影响原有功能流程
6. 用户可选择取消操作，不强制下载

## 实现优先级
- P1: 核心功能实现（SM2加密/解密/签名/验签）
- P2: SM3哈希和SM4加密/解密支持
- P3: 代码优化和用户体验改进
